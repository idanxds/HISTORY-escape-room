# בראשית: המשחק

משחק כיתתי בסגנון קהוט: המארח על המסך הגדול, השחקנים בטלפון (סריקת QR).

## הרצה מקומית
```
npm install
npm start
```
- מארח: http://localhost:3000/host  (על המחשב המחובר למקרן)
- שחקנים: סורקים את ה-QR שמופיע בלובי (הטלפונים חייבים להיות על אותה רשת Wi-Fi)

## הרצה בשרת ציבורי (מומלץ לכיתה)
מעלים לשירות כמו Render / Railway (Node, פקודת הרצה `npm start`). אין צורך בהגדרות.
משתני סביבה אופציונליים: `HOST_PIN` (קוד סודי למארח), `PUBLIC_URL` (כתובת קבועה ל-QR).

## בדיקה אוטומטית
`npm start` בחלון אחד, ובחלון שני: `npm test` (מארח + 12 בוטים משחקים משחק שלם).

## עריכת תוכן
- `content.js`: חיות לסבב 1 ושאלות הטריוויה (כולל התשובה הנכונה).
- `public/common.js`: טקסטי הפתיחה, פסוקים, לשונות הנחש, חיות התיבה.
- `server.js`: משך כל שלב (`TIMED`), ניקוד.
