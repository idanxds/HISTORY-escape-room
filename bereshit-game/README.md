# בראשית: המשחק

משחק כיתתי בסגנון קהוט: המארח על המסך הגדול, השחקנים בטלפון (סריקת QR).
ארבעה סבבים לפי ספר בראשית, ואחריהם טריוויה:

| סבב | פרק | מה עושים |
|---|---|---|
| 1 · **אדמה** 🌱 | ב — "וַיִּקְרָא הָאָדָם שֵׁמוֹת" | נותנים שם מצחיק לחיה ומצביעים לשם הכי טוב |
| 2 · **אכל** 🌳 | ג — "מִכֹּל עֵץ־הַגָּן אָכֹל תֹּאכֵל" | אוכלים פירות לסל — ועוצרים לפני שאוכלים מעץ הדעת |
| 3 · **שחת** 🌊 | ו–ז — "שְׁנַיִם שְׁנַיִם בָּאוּ אֶל־נֹחַ" | מוצאים בן זוג עם אותה חיה ועולים לתיבה |
| 4 · **פוץ** 🧱 | יא — "הָבָה נִבְנֶה־לָּנוּ עִיר וּמִגְדָּל" | שני צוותים בונים מגדל, ואז שאלות על בראשית א–יא |

## הרצה מקומית
```
npm install
npm start
```
- מארח: http://localhost:3000/host  (על המחשב המחובר למקרן)
- שחקנים: סורקים את ה-QR שמופיע בלובי (הטלפונים חייבים להיות על אותה רשת Wi-Fi)

במסך המארח: **רווח** או **←** = השלב הבא, **F** = מסך מלא, **M** = צלילים.
הפונטים שמורים בתיקייה `public/fonts`, כך שהמשחק נראה נכון גם בלי אינטרנט.

## הרצה בשרת ציבורי (מומלץ לכיתה)
מעלים לשירות כמו Render / Railway (Node, פקודת הרצה `npm start`). אין צורך בהגדרות.
משתני סביבה אופציונליים: `HOST_PIN` (קוד סודי למארח), `PUBLIC_URL` (כתובת קבועה ל-QR).

## בדיקה אוטומטית
```
npm test
```
הבדיקה מפעילה שרת משלה ובודקת שני דברים (כ-20 שניות):
1. **תוכן מול נוסח 929** — כל ציטוט במשחק נבדק מילה במילה, כולל ניקוד, מול נוסח בראשית
   השמור ב-`tools/genesis929.json`. בנוסף: אין תפוח, ושם ה' המפורש לא כתוב במלואו בשום מקום.
2. **משחק מלא** — מארח + 12 בוטים משחקים את כל הסבבים: ניקוד בכל סבב, שחקן שמצטרף באמצע,
   התחברות מחדש, שמות כפולים, ומשחק חדש.

לבדיקת שרת שכבר רץ: `URL=http://localhost:3000 npm test`

## מקורות
- **הכול מספר בראשית בנוסח המסורה, כפי שמופיע באתר [929 – תנ"ך ביחד](https://www.929.org.il)**,
  בניקוד של 929 ובמספור הפסוקים העברי (למשל בראשית לב, ו — ולא לב, ה כמו בתרגומים).
- שם ה' המפורש כתוב **ה'**, כמו בסיכומי הפרקים של 929.
- כותרות הסבבים ("צריך אדם? נעשה אדם", "כאן התחילו הצרות", "חוזרים לתוהו",
  "כך בונים מגדל - כך נופל מגדל") הן כותרות הפרקים באתר 929, עם קישור לכל פרק.
- **אין תפוח.** התורה לא אומרת מה היה פרי עץ הדעת; שאלה בטריוויה מלמדת זאת, עם דעות חז"ל.
- שתי הערות בטריוויה מצטטות מקורות שאינם בתנ"ך ולכן לא נבדקות מול 929:
  רש"י על בראשית ב, כא ("מצלעותיו — מסטריו"), ותלמוד בבלי ברכות מ ע"א (גפן / חיטה / תאנה).

## עריכת תוכן
- `content.js`: חיות לסבב 1, ומאגר הטריוויה (28 שאלות; בכל משחק מוגרלות 6, לפי סדר הפרקים).
- `public/common.js`: טקסטי הפתיחה, פסוקים, לשונות הנחש, חיות התיבה.
- `server.js`: משך כל שלב (`TIMED`), ניקוד.

שאלת טריוויה חדשה צריכה את השדות:
```js
{ q: 'השאלה', options: ['א', 'ב', 'ג', 'ד'], correct: 1,   // אינדקס התשובה הנכונה
  ch: 8, v: 11, ref: 'בראשית ח, יא',                       // הפסוק שמוכיח את התשובה
  quote: '...ציטוט מנוקד, מועתק מ-929...',
  group: 'birds',                                         // אופציונלי: לא שתי שאלות מאותה קבוצה במשחק
  note: '...' }                                           // אופציונלי: הסבר שמוצג אחרי החשיפה
```
אחרי שינוי מריצים `npm test`. אם הציטוט לא תואם לפסוק — הבדיקה תיכשל ותגיד איפה.
כדי לצטט פרק שלא שמור ב-`tools/genesis929.json`, צריך להוסיף אותו מ-929.
